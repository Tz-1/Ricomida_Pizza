# Ricomida 

## Description
Ricomida is a simple website featuring recipes of various dishes. You can order food from the website as well.

## Technologies Used
- **HTML**
- **CSS**
- **Bootstrap**
- **JavaScript**

## Features
- **Responsive Design**: Built with Bootstrap  for seamless display across different devices.
- **Recipe Sections**: Organized ingredients and step-by-step preparation guide.
- **Newsletter Subscription**: Allows users to subscribe for updates.
- **JavaScript Enhancements**: Includes tooltips and interactive buttons.

## Technologies Used
- **HTML5**
- **CSS3**
- **Bootstrap 5**
- **JavaScript**
